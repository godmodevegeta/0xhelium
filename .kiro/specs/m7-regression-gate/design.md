# Design: M7 — Independent regression gate and policy promotion

## Files

| Path | Role |
| --- | --- |
| `examples/m7/gate-v1.json` | Pre-registered gate: registry, primary rule, suites, criteria (generated by `scripts/make_gate_config.py`, committed before evaluation) |
| `presets/m6-candidates-v1/` | The five M6 CLI candidate records (seeds 0–4), hash-listed |
| `src/robustlab/gate/config.py` | Load and verify the gate config; build episode specs; primary rule |
| `src/robustlab/gate/evaluate.py` | Run suites for baseline and candidates (M6 evaluator and process pool), compute criteria, McNemar, Wilson |
| `src/robustlab/gate/registry.py` | Policy registry: baseline v0, immutable promoted versions, rejections, atomic active pointer |
| `robustlab gate` CLI | Run once; write `runs/m7/gate-v1/gate_result.json`; apply the decision to the registry |
| `presets/m7-gate-v1/` | The committed gate result (for the app) |
| `src/robustlab/api/gate.py` | `GET /api/gate`, `GET /api/gate/replay` |

## Evaluation

All episodes go through `adapt.evaluate.run_episode` (the M6 metric code; no new physics). Nominal
episodes are run in-process with records kept, so displacement can be computed; gauntlet and
attack episodes use the M6 process pool (metrics only). Per controller:
13 locked + 13 nominal (3 locked counted once) + 1280 gauntlet + 34 known ≈ 1337 episodes; six
controllers ≈ 8000 rollouts, about 1 minute on 8 processes.

Displacement (G1): `d = R(-yaw0)·(xy_last_valid − xy_0)`, compared as
`‖d_c − d_b‖ ≤ max(0.10, 0.10·‖d_b‖)`.

McNemar (G2): b = baseline fell & candidate survived, c = baseline survived & candidate fell,
`p = Σ_{k≥b} C(b+c, k) / 2^(b+c)` (1.0 if b + c = 0).

## Registry

`policies/registry/versions/v0-baseline.json` (frozen policy sha, no reflex),
`policies/registry/versions/v<N>-<cand>.json` (parent, candidate record sha, calibration sha, gate
result sha), `policies/registry/rejected/<cand>-gate-v1.json`, and `policies/registry/active.json`
(written via temp file + rename). Version files are never overwritten.

## Once-only

The gate writes `runs/m7/gate-v1/` and refuses if `gate_result.json` exists there or a committed
`presets/m7-gate-v1/gate_result.json` exists for the same config sha, unless `--verify` is given,
which recomputes and compares without touching the registry.
